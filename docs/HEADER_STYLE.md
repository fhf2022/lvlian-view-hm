# 自绘页头统一规则

文件、共享、传输、设置及其子页、图片和视频浏览使用同一套 `HeaderStyle` 参数。相册选择承载页、相册确认和明细也沿用同样的标题、控件和边距；系统相册列表由官方组件提供。

| 项目 | 规则 |
| --- | --- |
| 标题 | 20 fp、粗体、左对齐，单行超出省略 |
| 页面左右边距 | 16 vp |
| 返回、关闭及图标控件 | 40 × 40 vp，图标 24 fp |
| 控件及标题间距 | 8 vp |
| 无返回按钮 | 标题从左侧 16 vp 开始，不保留隐藏按钮占位 |
| 有返回按钮 | 返回按钮从 16 vp 开始，标题从 64 vp 开始 |
| 右侧操作 | 对齐右侧 16 vp 边界，按实际操作数量占位 |

普通页面的操作行使用原有 94 vp 材质承载高度：上方 8 vp、行高 56 vp、下方渐变区 30 vp。控件和标题垂直中心位于顶部安全区下方 36 vp。视频页也使用该位置，保留安全区放在 Navigation 外侧的实现，以免旋转时重建投屏控件。搜索承载层仍固定为 136 vp，输入过程中不改变高度。

相册选择卡片从顶部安全区下方 8 vp 开始，头部行高 56 vp，标题和关闭按钮同样对齐页面操作行。保留顶部圆角、卡片外原页面以及系统相册列表底部沉浸。

明细弹层的关闭按钮由系统放置，头部使用相同的 16 vp 上边距，让标题、筛选、刷新与原生关闭按钮垂直居中。按钮高 40 vp，彼此相隔 8 vp。

普通标题统一由 `mainHeaderTitle()` 决定，返回区域由实际页面层级决定。设置子页统一由 `hasSettingsSubpage()` 识别，包含默认视图；点击返回调用对应关闭函数，回收站仍逐级返回。默认视图页补齐标题和返回入口，并按其他设置子页规则隐藏主页底栏。

## 转场、快照和启动

目录转场使用 `DirectoryHeaderState` 一起保存当前绘制页面的路径、标题和返回状态。进入目录的准备帧保持出发页状态，动画开始后切换到目标页；返回时即使真实内容仍保留子目录，顶栏、底栏模式和悬浮上传入口也已经采用返回目标。接管与取消转场时释放该状态，旧完成回调受转场 token 保护。

标题随页面同步提交，移除旧的 45 ms 延时改字和淡出。返回/关闭控件使用常驻材质节点；无返回入口时以 `Visibility.Hidden` 禁止绘制和触摸，同时外层宽度归零。设置切换清除旧的默认视图子页标记。

父目录快照先按当前排序规则整理，真实页面接管时直接使用同一份结果，不再接管后重新排序。排序生成新的数组，原缓存条目顺序不变；因此没有增加一次重复排序。列表和网格仍沿用原有滑动动画及滚动恢复。

搜索结果打开文件夹时保持搜索页直到目标目录准备完成，再一次提交目标页面。搜索页不再被重建成来源目录的快照，返回仍恢复原搜索会话；关闭搜索或切换页面后忽略迟到的目录读取。

搜索覆盖目录时保留 FileContent 子树，通过 Hidden 关闭绘制并阻断其输入，搜索内容使用页面底色。直接关闭搜索不再重新绑定原目录或清空预览；从结果返回时，仅目录或视图确实改变才恢复目录数据和滚动快照。同一目录已追加的分页继续保留。输入框使用稳定 id，在可见回调中执行一次主动获焦；关闭键盘会取消尚未执行的获焦，搜索范围切换、结果返回不自动弹键盘。

启动恢复期间显示与页面一致的背景、应用的蓝底白色文件图标（`app.media.icon`，也是实况窗的应用标志资源）及加载环。根目录与默认用户目录在内存中准备后一次提交，并等待恢复页完成一帧再揭开启动覆盖层。主页切换也等目标目录就绪后提交，失败时才进入可用的根目录。

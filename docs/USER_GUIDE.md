# 联文件使用说明

[返回项目首页](../README.md) · [开发与构建](DEVELOPMENT.md) · [文档目录](README.md)

本说明按当前开发版本整理，应用市场中的版本可能存在界面差异。当前仅适配绿联 NAS，设备需支持 HarmonyOS API 26。

## 1. 首次打开与登录

1. 阅读并同意开屏隐私声明，进入应用。
2. 根据系统弹窗决定是否允许读取图片和发送通知。图库权限用于整相册上传，拒绝后仍可使用 NAS 文件浏览；通知用于传输进度和后台保护。
3. 填写绿联云盘 ID，可先点击「解析」检查地址是否可用。
4. 输入 NAS 账号与密码登录；如果 NAS 开启了安全验证，按提示填写验证码。

「记住地址」保留设备入口；「自动登录」会保存后续登录所需的凭据。请使用拥有目标目录访问权限的账号。连接失败时先确认手机网络、NAS 开机状态和云盘 ID，不必反复退出账号。

## 2. 浏览与整理文件

- 底部导航切换个人目录、共享目录、传输和设置；目录里的返回按钮回到上一级。
- 文件目录可按名称、类型、时间和大小排序，并按目录内容选择列表、网格或瀑布流。用户根目录等入口有自己的固定布局。
- 点击图片进入查看器，可切换、缩放、拖动返回并查看详情。包含日期信息的图片目录可使用时间轴定位。
- 点击音频或视频播放，支持时可使用系统投屏或画中画。能否播放仍取决于文件编码和设备能力。
- 视频底部可暂停、拖动进度和切换横竖屏；本地播放点击倍率文字可调节 0.25×～4×，点击滑杆下方中间的重置图标，或长按未展开的倍率文字，可恢复 1×。长按画面临时 2×，松手恢复所选倍率。系统返回先收起已打开的倍速浮层。
- 视频画面横滑可预览进度，松手跳转；左半边上下滑调节本窗口亮度，退出恢复原亮度，右半边上下滑通过系统音量条调节媒体音量。播放时长按画面 350 ms 临时加速至 2×。双击暂停／继续，单击显示／隐藏控件；闲置 4 秒自动隐藏，拖动或打开倍速浮层时保持显示。
- 长按文件打开操作菜单，可执行重命名、复制、移动、下载、分享或删除；可用操作随文件类型、目录及 NAS 权限变化。

复制或移动时，先选择 NAS 目标目录，再点击底部确认按钮。删除后如需还原，可在「设置 → 回收站」查看个人或共享回收站。

### 音频播放与默认视图（1.0.11）

打开音频后进入独立播放页，可播放、暂停、切歌、拖动进度、切换循环方式及选择播放列表中的曲目。播放列表使用当前目录或搜索结果中已经加载的音频；同目录同名 `.lrc` 可作为歌词，不提供在线歌词搜索。文件列表、网格和系统播控中心显示可读取到的专辑封面，无封面时使用音频图标。

封面打开、返回时与对应文件位置衔接，返回文件页会停止本次播放。切到后台时能否继续播放由「设置 → 播放与控制」及系统策略决定。

「设置 → 默认视图」可分别设置普通文件、图片和音频目录。初始为普通文件夹列表、音频列表、图片网格；已保存的选择不会被升级覆盖。音频默认适用于纯音频目录，带有其他文件或子目录的混合目录沿用普通文件默认。

### 连续多选

进入多选后，点击一项切换其选中状态。长按后拖动，以首项和当前末项之间的连续范围为准，**相对于本次拖选开始前的状态反转选中**；向回拖时范围会随末项收缩。靠近顶边或底边并保持拖动可自动滚动，继续扩展范围。

例如原来已选中 B，拖选范围从 A 到 C 后，A、C 会选中，B 会取消选中。普通滑动仍用于浏览；需要先长按，再拖动进行连续选择。

## 3. 上传文件与图片

### 普通上传

1. 打开 NAS 上准备接收文件的文件夹。
2. 点击悬浮加号，选择文件或图片入口，在系统选择器中完成选择。
3. 确认目标后开始上传，在「传输」页切换到「上传」查看状态。

普通文件上传与整相册上传的冲突策略不同：普通上传的确认会提示同名文件跳过；整相册任务按下一节的规则处理。

### 整个图库文件夹上传

1. 如果有只在华为云中的照片，先打开**系统图库**，对相册执行缓存或下载原图，等待完成。
2. 回到联文件，进入 NAS 目标图片文件夹，点击 **悬浮加号 → 图库文件夹**。
3. 在系统相册列表选择一个相册。
4. 核对确认页上的**相册名、可上传数量、NAS 目标**；刚刚缓存了照片时，点击「刷新数量」。
5. 点击「开始上传」。应用整理出本批图片清单后，在「传输 → 上传」中显示一条相册任务。

这项功能按**创建任务时的清单**上传，不会持续跟随相册变化。相册扫描期间发生变更可能导致创建失败，此时刷新后重新创建；任务建立后图片被编辑、删除或不可读取，会记录为失败，不会悄悄上传其他版本。

| 目标 NAS 中的情况 | 处理方式 |
| --- | --- |
| 没有对应文件 | 上传 |
| 同名且同大小 | 跳过，计入已处理数量 |
| 同名但大小不同 | 生成备用名称，保留两份 |
| 不同名称、内容相同 | 不进行跨文件内容哈希去重，可能再次上传 |

上传会保留手机原图和 NAS 已有文件。可上传数量只统计本机可读取的图片；系统列表总数可能包含云端资源，因此两者不一定相同。动态照片只上传静态图片部分，视频不在这一批中。

当前整相册任务仅使用 Wi-Fi；最多保留 5 个未完成的相册任务。出现数量上限提示时，先完成或移除已有任务。

## 4. 传输、后台与重试

在「传输」页右上角的胶囊切换「下载 / 上传」。普通文件与相册任务都显示名称、状态和进度。

相册任务可点击执行暂停、继续或重试；已完成任务可进入图片明细。长按相册任务可查看可用操作，明细支持「全部 / 失败」筛选。移除任务记录会停止本批任务，**已经上传到 NAS 的图片仍会保留**。

### 后台传输的条件

允许应用通知并开启系统传输通知相关渠道后，应用会在实际传输时申请数据传输保护，并通过系统通知显示总进度。保护有效时可以切换应用或锁屏；点击通知可回到传输页。

如果通知关闭、系统拒绝保护或通知更新失败，任务仍可在前台运行，切后台时等待前台恢复。用户取消系统保护后，需要回到应用继续任务。保持亮屏不是后台传输的必要条件。

总进度按照当前会话需要处理的字节汇总，跳过的图片计入已处理量，不计入网络上传速度。加入新任务可能改变总大小；有失败项时请查看失败明细，不能只看环形进度。

强行结束进程、重启设备或长时间网络不可用后，请重新进入应用检查任务。后台保护不等于系统始终保持进程运行。

### 下载保存在哪里

首次下载或需要重新授权时，应用会通过系统文件选择器取得下载目录权限。文件下载并保存成功后才算完成；若显示等待保存或保存失败，回到前台处理授权后再重试。浏览图片形成的缓存与主动保存的下载文件用途不同。

## 5. 缓存与 NAS 离线

「设置 → 缓存与存储」可以查看缓存占用、调整上限或清理缓存。「网络与流量」控制移动网络下的加载和传输策略；「默认视图」和「播放与控制」分别管理浏览和播放偏好。

NAS 不可达时，应用会保留当前目录、滚动位置和任务；已经缓存的内容仍可使用。没有缓存的原图或目录需要等待连接恢复。连接恢复后，原本运行中的传输会按网络策略继续，手动暂停的任务仍需手动继续。

缓存上限不是离线下载承诺：缓存可能被清理，重要文件应主动下载并确认保存成功。网络失败期间的复制、移动、重命名、删除结果可能尚未确认，恢复连接后先刷新检查，再决定是否重新操作。

## 6. 权限说明

| 权限或系统授权 | 用途 | 不允许时 |
| --- | --- | --- |
| 读取图片和视频（`READ_IMAGEVIDEO`） | 读取所选相册的图片、名称、大小和修改时间，建立并执行批量上传任务 | 整相册上传不可用，NAS 浏览仍可用；普通图片选择按系统选择器授权范围处理 |
| 通知 | 显示传输总进度，并配合后台传输保护 | 传输可能仅在前台进行，可从传输页进入系统通知设置 |
| 系统文件选择、下载目录授权 | 访问主动选择的本地文件和保存下载文件 | 对应上传或保存操作无法完成 |
| 后台运行声明 | 支持数据传输与音频播放 | 实际运行受系统策略、通知及任务状态控制 |
| 网络与振动 | 连接 NAS、识别网络状态和操作触觉反馈 | 网络不可用时等待恢复；触觉反馈遵守系统设置 |

开屏隐私声明与系统权限弹窗分别展示。同意隐私声明不等于已经授予图库读取或通知权限。此前拒绝图库授权时，在相册流程点击允许读取图片，可按系统弹窗恢复；也可以在系统应用设置中调整。

## 7. 常见问题

**相册有很多照片，为什么可上传数量少？**

先检查缺少的照片是否仍在云端。仅有缩略图不代表原图已落地；进入系统图库缓存原图后，回到确认页刷新数量。确认图库权限已允许，视频也不会计入本次图片批量上传。

**上传完成后，相册新增的照片为什么没有跟着上传？**

这是一次上传任务，不是常驻同步。对同一 NAS 目标再次创建相册任务即可检查当前清单；同名同大小的已有图片会跳过。

**切后台后为什么暂停？**

查看传输页的提示，确认应用通知、相关通知渠道和网络可用。后台保护未取得时，需要保持应用在前台；整相册上传还需要 Wi-Fi。强制停止后请重新打开应用。

**通知中心有进度，为什么没有自定义状态栏实况窗？**

系统数据传输通知与自定义实况窗是不同能力。当前使用说明以系统进度通知为准，不将自定义胶囊展示作为后台传输的前提。

**NAS 关机后需要重新登录吗？**

先让 NAS 恢复联网，再点击重试。网络断开不等于账号失效；明确提示会话或账号失效时再重新登录。离线能查看的内容取决于此前缓存。

**如何报告问题？**

在 [GitHub Issues](https://github.com/fhf2022/lvlian-view-hm/issues/new/choose) 选择问题模板，提供应用版本、设备及系统版本、NAS 型号与系统版本、复现步骤，以及预期和实际表现。请将账号、云盘 ID、私有地址、文件名和令牌等信息遮盖后再附图或日志。

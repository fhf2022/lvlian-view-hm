# 媒体和弹层返回时保留原页面控件

2026-10-05：视频、音频、长按菜单和重命名原先参与底栏、悬浮按钮及标题栏的 `if` 条件，打开时删除节点，关闭后重新创建。文件工具栏的显示条件还改变了底栏形态，并使时间轴进入隐藏状态。这会重新初始化原生材质；悬浮按钮也会再次异步读取停靠位置。

现在与图片查看器使用相同的保留方式：

- 底栏和标题栏按所在页面挂载，不随媒体或菜单状态卸载。底栏形态只取决于基础页面、多选和搜索状态。
- 悬浮按钮在文件目录内保留实例。搜索和多选只改变可见性，停靠位置与材质实例保留。
- 时间轴按原目录、排序和尺寸判断是否应显示；媒体与弹层不改变基础页面的判断。路径选择覆盖时将时间轴降到 zIndex 8，处于选择页下方。
- 视频和音频的覆盖层使用 zIndex 30。画中画仍将原视频宿主缩至 1 vp，并继续保留原 XComponent。
- `parentOverlayOwnsInteraction()` 统一隔离底层控件输入，同时阻止根触摸路由在覆盖层出现时把事件转发到文件列表。图片返回的提前释放逻辑沿用原 `viewerOwnsParentInteraction()`；文件内容宿主始终保持 Default，不新增动态 BLOCK_DESCENDANTS。

官方条件渲染机制已通过 devecocli 查阅：分支变化会移除旧子组件并构造新分支。相关原生材质宿主的挂载条件因此与短期弹层状态分离。

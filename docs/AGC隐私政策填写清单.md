# AGC 隐私政策模板 · 填写清单（按"仅提供连接工具"定位）

## 1.0.10：跨设备接续

接续开发版没有新增用户授权权限。正式发布包含接续的版本前，需在关联托管政策的数据处理说明中同步本地[隐私政策草稿](隐私政策.md)的接续用途、传递的目录信息与账号校验标识、临时保存及清理方式。当前在架 1.0.9 的协议不因源码修改自动更新。

系统分享上传也未新增用户授权权限，使用来源应用通过系统授予的文件临时读取权限。发布前将草稿第二节中“用户从其他应用分享文件、选择目标并确认后读取与暂存上传”的用途及清理方式同步到正式托管政策。

## 2026-10-14：1.0.9 必须补充图库权限

如果 AGC 提示“只在软件包中的权限：[READ_IMAGEVIDEO]”，在当前待提交版本关联的隐私政策中，进入“2. 设备权限调用”，添加“图片和视频／读取图片或视频”对应的 `ohos.permission.READ_IMAGEVIDEO` 权限项。仅在自定义章节写用途不能代替这个结构化权限项。

若现有协议为“完成”，操作栏只有“复制”而没有“编辑”，先使用该协议的“复制”创建修改用的新协议，命名为“联文件隐私政策-1.0.9”。在新协议中补充权限，生成协议后回到待提交版本，关联新协议；保留旧协议供在架版本使用。

用途可填写：

```
用于读取您选定相册中的图片、名称、大小和修改时间，统计可上传数量，并在您确认后将图片批量上传至您指定的 NAS。拒绝授权不影响 NAS 文件浏览，您可在系统设置中撤销权限。
```

保存修改后，在待提交的 1.0.9 版本“隐私声明”处确认关联修改后的政策，再重新提交权限一致性检查。现有软件包与发布 Profile 已包含此权限；本次反馈缺少的是政策声明。

**核心定性（贯穿全文，别动摇）**：
> 本应用**仅提供客户端工具**，用于连接用户**自有**的 NAS。
> 应用按用户操作读取本地数据，并上传到用户指定的 NAS；开发者不提供文件存储服务器。
> 权限及数据处理描述必须与当前版本实际行为一致。

填写必填项，并按实际使用的权限和数据补充相应章节，不沿用旧版“全部权限安装即授予”的结论。

## A · 摘要（点「增加摘要」）

```
本应用提供连接您自有 NAS 的客户端工具。在您的操作和授权下，应用读取本地图片并上传至您指定的 NAS，或从 NAS 浏览、下载文件。应用不提供云存储服务、不提供注册账号，不包含广告与个性化推荐。
```

## B · 7.1 固定存储期限（0/512）

```
本应用不收集、不存储您的任何个人信息，亦不存在固定的存储期限。您填写的云盘 ID 与登录账号仅保存在您的设备本地，登录密码交由系统密码保险箱保管，本应用不保存明文；目录索引、缩略图与下载缓存亦仅存于本机，可在「设置 → 缓存与存储」中随时清除，卸载应用即全部删除。
```

## C · 7.2 传输并保存至（0/100）

中国境内（您的信息仅保存在您自己的设备上；您的文件始终保存在您自己的云盘设备中）

## D · 第 8 章 · 开发者自定义章节（最重要）

```
一、关于本应用的定位
本应用仅提供客户端工具，用于连接您自己拥有并自行管理的云盘（NAS）设备。我们不提供云存储服务，也不提供注册账号，与云盘设备品牌方不存在隶属、代理或合作关系。

二、关于数据传输
在您的指示与操作下，本应用将您填写的云盘 ID 与登录凭据发送至您自己指定的云盘设备，用于完成登录与文件访问。上述信息由您的设备直接发送，我们不收集、不中转、不存储这些信息，也不存在本应用向任何第三方共享您个人信息的行为。
当您的手机与云盘设备不在同一局域网时，设备寻址与连接建立可能依赖设备厂商提供的网络服务，该过程发生在您的设备与该服务之间，我们不参与、不获取其中的内容。

三、关于文件
应用按您的操作从 NAS 浏览和下载文件，或将您选定的本地图片、文件上传至您指定的 NAS。相册批量上传会读取选定相册中的图片及名称、大小、修改时间，并在本机保存任务清单和进度以支持暂停、继续与重复文件检查。上传不删除本地原图；临时传输文件在处理结束后清理。文件导出的保存位置由您在系统界面中选择。

四、关于系统权限
1. 网络访问：连接您自己的云盘设备并传输文件，为本应用核心功能所必需。
2. 获取网络状态：判断是否处于局域网，以选择合适的连接方式。
3. 后台运行：切换到其他应用时支持视频、音乐播放及用户发起的上传下载；传输时在通知中心展示进度，可暂停任务。
4. 震动：长按、多选等操作的触感反馈，可通过系统设置关闭。
5. 读取图片和视频（READ_IMAGEVIDEO）：用于读取您选定相册中的图片及名称、大小、修改时间，统计数量并批量上传至您指定的 NAS。当前批量上传仅处理图片，不处理视频。首次隐私声明同意后申请授权，拒绝不影响 NAS 浏览，可在系统设置中撤销。
本应用不申请定位、相机、麦克风、通讯录、短信、通话记录、日历、健康数据等与功能无关的权限，也不申请读取公共存储目录的权限。

五、关于未成年人
本应用面向成年人，不面向未成年人，也不会有意收集未成年人的个人信息。

六、关于删除与卸载
本应用不保留任何与您相关的数据；您可随时清理缓存或卸载应用以清除全部本地数据。
```

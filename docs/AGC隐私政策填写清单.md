# AGC 隐私政策模板 · 填写清单（按"仅提供连接工具"定位）

**核心定性（贯穿全文，别动摇）**：
> 本应用**仅提供客户端工具**，用于连接用户**自有**的云盘设备。
> 我们不收集、不上传、不存储、不中转用户的任何个人信息和文件；
> 用户的数据始终在**用户自己的手机与用户自己的设备**之间流动，**我们不参与其中**。

**由此推出的原则**：本应用**不是个人信息的处理者**，因此模板中凡属"处理者义务"的章节一律不填
（共享、SDK、信息访问/更正、儿童声明等）。**只填带 * 的必填项 + 第 8 章自定义说明。**

## A · 摘要（点「增加摘要」）

```
本应用仅提供客户端工具，用于连接您自己的云盘（NAS）设备。我们不收集、不上传、不存储、不中转您的任何个人信息与文件：您填写的信息仅保存在您的设备本地，您的文件始终保存在您自己的设备上，数据在您的手机与您的设备之间直接流动，我们不参与其中。本应用不提供云存储服务、不提供注册账号、不包含广告与个性化推荐。
```

## B · 7.1 固定存储期限（0/512）

```
本应用不收集、不存储您的任何个人信息，亦不存在固定的存储期限。您填写的云盘 ID 与登录账号仅保存在您的设备本地，登录密码交由系统密码保险箱保管，本应用不保存明文；目录索引、缩略图与下载缓存亦仅存于本机，可在「设置 → 缓存与存储」中随时清除，卸载应用即全部删除。
```

## D · 第 8 章 · 开发者自定义章节（最重要）

```
一、关于本应用的定位
本应用仅提供客户端工具，用于连接您自己拥有并自行管理的云盘（NAS）设备。我们不提供云存储服务，也不提供注册账号，与云盘设备品牌方不存在隶属、代理或合作关系。

二、关于数据传输
在您的指示与操作下，本应用将您填写的云盘 ID 与登录凭据发送至您自己指定的云盘设备，用于完成登录与文件访问。上述信息由您的设备直接发送，我们不收集、不中转、不存储这些信息，也不存在本应用向任何第三方共享您个人信息的行为。
当您的手机与云盘设备不在同一局域网时，设备寻址与连接建立可能依赖设备厂商提供的网络服务，该过程发生在您的设备与该服务之间，我们不参与、不获取其中的内容。

三、关于文件
您通过本应用访问的图片、视频与文件始终保存在您自己的设备上，我们不上传、不备份、不分析其中内容。文件的导出通过系统选择器完成，保存位置由您自行选择。

四、关于系统权限
1. 网络访问：连接您自己的云盘设备并传输文件，为本应用核心功能所必需。
2. 获取网络状态：判断是否处于局域网，以选择合适的连接方式。
3. 后台运行：切换到其他应用时使视频与音乐继续播放，可在应用内关闭。
4. 震动：长按、多选等操作的触感反馈，可通过系统设置关闭。
本应用不申请定位、相机、麦克风、通讯录、短信、通话记录、日历、健康数据等与功能无关的权限，也不申请读取公共存储目录的权限。

五、关于未成年人
本应用面向成年人，不面向未成年人，也不会有意收集未成年人的个人信息。

六、关于删除与卸载
本应用不保留任何与您相关的数据；您可随时清理缓存或卸载应用以清除全部本地数据。
```

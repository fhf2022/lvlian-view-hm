# 2026-10-23 审核问题修复与待测项

基线：6fe77ad，版本仍为待发布 1.0.10。此次不改导航结构、图片共享元素动画或播放器布局。2026-10-23 已覆盖安装到手机 `10.16.100.140:27677`，以下区分本机回归、已完成的真机抽查和剩余验收。

## 实现

- 普通下载以已有账号 scope、文件签名及保存目标去重。展示、调度、操作、异步完成与保存均校验账号；从旧签名恢复可确认的账号，无法确认归属的旧记录不自动归入当前账号。
- 普通下载、视频分段与原图缓存使用共同的远端版本比较和条件续传。ETag 或大小冲突清除旧分段；普通下载和视频优先以强 ETag 通过 If-Range 绑定续传，无 ETag 时允许使用已验证的 Last-Modified（响应 Date 至少晚 60 秒），缺失或冲突的验证值、分段总大小变化在写入前拒绝。无有效验证值的旧断点重新开始。原图预加载仍采用原强 ETag 策略，不新增磁盘元数据文件。完整缓存仍按账号与列表版本命中；不增加目录查询、全文件校验或媒体加载并发。
- 查看原图后生成的缩略图显式使用 repository 文件签名，旧无账号派生图不再命中。预览 URI 版本包含账号及可用验证字段，迟到的生成结果不会发布到其他目录／账号。
- 视频显式下载继续复用分段缓存，使用同一个 TransferRunPolicy 和 TransferBackgroundManager，接入通知总进度、后台保护、移动网络限制和系统取消。多个视频通过一条串行下载通道执行；普通下载本身仍有一条串行通道。显式下载在入队后返回，不再全程占用页面 busy；需要完整文件的保存／分享继续等待 requestCachedFile。
- 普通下载与视频投影列表保持 @Observed 任务对象稳定，修复下载／暂停状态在行组件中滞留旧值；HTTP 续传校验字段与列表身份字段分开保存，避免恢复时生成重复视频任务。
- 自动登录密码迁入 Asset Store Kit，首次解锁后可访问、不同步、不保留卸载凭据；仅迁移成功后清除旧 Preferences 字段。关闭自动登录删除系统资产；系统服务失败时保留迁移前唯一副本，界面不假报保存成功。隐私文案同步描述系统资产存储，未新增权限。
- 备份排除登录配置、传输暂存及设备绑定任务索引、相册上传清单和可重建缩略图。备份／恢复路径是否完全覆盖设备实际存储布局仍需系统级验证。
- CacheManager 发布物理删除通知；缩略图索引按反向索引删除对应别名，页面批量清理至多 512 项 URI 缓存。渲染查询不增加 stat。Image 加载失败只异步检查该文件，每个身份有限恢复；有效文件的解码失败不会触发反复 NAS 下载。正在加载的旧请求结束后补发被删除项的加载。
- 缩略图索引启动改异步读文件，不逐条同步验证磁盘；容量维护每批最多 8 个异步 stat，索引修剪留出少量容量，减少持续浏览中的反复全表排序。
- 重命名成功直接关闭弹窗，迁移查看器、选中状态、位图和返回定位；旋转元数据按新路径迁移。目录刷新失败不会把已成功的重命名报告为失败。
- 视频 AVPlayer 在开始创建前捕获代次，迟到实例由创建方释放；配置过程的 await 边界检查所有权。
- 保存图库在统一 finally 中分别释放 helper、源及目标句柄，覆盖取消和目标打开失败。
- 大相册条目状态与批次数量在同一 SQLite 事务内增量更新；恢复、重试和批次边界 recount。待处理查询使用部分索引，避免每项都排序整批；保留原冲突和 ledger 规则。
- 临时图片跟踪开关按 BuildProfile.DEBUG 控制，保留已验证的 R2／R3.2 行为开关。

## 续传响应头复核（2026-10-23）

- 下载令牌接口返回字段为 dl_token、dl_url，没有 ETag／校验和／文件大小；这不代表实际文件响应没有其他版本信息。
- 真机 Photos/Screenshots 视频的文件响应返回 Accept-Ranges: bytes、HTTP 206、准确 Content-Range、Last-Modified 与 Date，没有 ETag。
- 使用 SVID_20240704_200211_1.mp4 的 Last-Modified 发起 bytes=1024-1024 的 If-Range 请求，返回 206、1 字节；故意替换为 1970 年日期时，不再返回 Content-Range，而是返回全文件长度，受限传输在写入前主动中止。未修改 NAS 原文件。
- 普通下载和视频分别持久化一个已验证的 HTTP 续传值，保持列表文件身份字段不变；共享响应校验，不扫描目录、不计算文件散列、不增加正常下载请求次数。新鲜、未来、无效或缺少 Date 的修改时间不会授权续传；存在弱 ETag 时不会转用日期。
- 新增回归覆盖日期匹配／变化／缺失、弱 ETag、日期时间差、跨描述符刷新／记录恢复、分段总大小冲突、完整回退替换以及替换文件变小后的完成状态。诊断日志与测试脚本保留在 temp/audit-fixes，临时 ResumeAudit 代码已移除。
- 最终调试包构建通过并覆盖安装，后台保护和存储回归通过。2.3 MB 视频在暂停动作完成前已下载完，完整的原生暂停／继续流程仍待验收；随后无线调试断开。新增下载副本留在系统下载目录，未修改 Screenshots 原件。
- 尝试将已有测试视频复制到 temp/test 时，NAS 返回操作失败；未用该请求作为续传通过的依据，目标目录仍待补查。

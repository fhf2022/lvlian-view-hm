# 选择与确认任务面板

复制／移动目标选择、系统相册选择、相册上传确认共用 `components/TaskPanel.ets`。几何集中在 `ui/TaskPanelStyle.ets`，标题尺寸、控制尺寸和边距继承 `HeaderStyle`。

列表密度继承 `ui/FileRowStyle.ets`：主文件列表、返回快照和目标目录列表共用 40×34 图标容器、32 图标、16／12 字号、8 水平间距和 12 上下内边距。官方相册组件设置同一正文字号，内部行高继续由系统管理。上传确认的数量采用同一正文字号，分组间距收紧为 8。

- `TaskPanel`：实色居中卡片、32 vp 圆角、标题栏和内容／底部操作插槽。文件夹／相册选择宽度为窗口 90%，最大 720 vp，两侧至少 16 vp；高度约 70%，优先保证系统安全区及窗口边缘间距。短窗口由外层滚动容器兜底，尺寸不随目录内容数量改变。
- 相册上传确认使用同一面板的 `compact` 模式，最大 420 × 380 vp。新建文件夹的两个入口共用 `CreateFolderDialog` 原生居中弹窗，宽度为窗口 84%、最大 420 vp。
- `TaskPanelHeader`：左侧标题、右侧关闭。目标选择仅额外提供新建文件夹按钮。
- `TaskPanelSection`：实色内容分组。列表使用零内边距，确认信息使用标准内边距。
- `TaskPanelFooter`：固定主要操作，必要时显示当前目标名称和路径。操作不再覆盖滚动内容。

亮色和暗色都使用无透明度的 `task_panel_*` 颜色，亮色白底、暗色 `#2E3033`；相册、文件夹和确认卡片不再逐处覆写颜色。面板自身不使用玻璃材质或背景模糊，卡片外以遮罩保留原页面。

## 内容与状态

展示层通过 Builder 插槽复用，NAS 目录列表和官方 `AlbumPickerComponent` 各自保留数据源。Builder 插槽通过调用方箭头调用独立 `@Builder` 方法，避免子组件改变 `this` 绑定；不要在箭头中直接编写原生 UI 或条件分支，否则可能导致复用行状态不刷新。

开屏使用 `StartupAuthorization` 检查官方托管隐私声明签署状态和版本，未同意时不初始化登录、NAS、图库任务或通知权限，也不允许进入页面。系统界面加载完成后再拉起官方隐私弹窗，拒绝／失败保留应用图标、简短提示、查看声明和退出入口。

用户同意开屏隐私声明后直接进入应用，不提前申请图库读取权限。展示系统相册列表也不申请；仅在用户点选具体相册、刷新数量或继续相册上传时，通过 `LocalAlbumSource.requestPermission()` 请求系统授权。此前拒绝导致普通权限弹窗无法显示时，显式相册操作可使用 `requestPermissionOnSetting` 拉起系统权限设置弹窗；本次刚拒绝则停止，不连续追问。图库拒绝不影响 NAS 功能，普通文件选择、系统分享和拖入文件使用系统授予的 URI 访问能力。相册页面不再拉起隐私声明。

上传确认只显示所选相册、可上传数量、NAS 目标、简短缓存提醒和传输规则。确认页可以刷新数量或更换相册；更换时用页面状态切回相册卡片。错误走已有沉浸通知，不插入红色说明块挤动内容。不把云端未缓存误判为系统集合不支持读取。

复制／移动从当前文件夹开始，返回键与“上一级”逐级返回到账户可见的根目录；选择器按层使用 `List + LazyForEach`。当前目录索引完整时直接复用已挂载条目，其他目录通过仓库的 `ensureDirectoryIndex` 复用缓存和进行中的索引，不再独立递归拉取目录树。

读取目录时可关闭，并通过请求令牌拒绝晚到的数据。复制、移动和新建目录写入期间禁止关闭及重复提交，失败后释放锁。相册任务准备状态由页面持有，任务创建使用开始时的 NAS 目标快照；系统手势关闭和返回键都遵守同一状态。关闭后的数量刷新／创建失败不再改写已销毁的子组件。

## 验证

`tests/task-panel-regression.cjs`、`tests/create-folder-dialog-regression.cjs`、`tests/destination-source-exclusion-regression.cjs` 覆盖尺寸边界、短窗口兜底、原生弹窗晚到、旧关闭回调、重复提交及源目录／后代过滤；既有目录与相册回归覆盖取消及读取生命周期。真机检查记录与截图保存在忽略的 `temp` 目录，不上传用户照片。

最终 debug 构建与保留数据的覆盖安装通过。真机验证包括已有隐私同意状态下的开屏进入、明／暗相册列表、暗色上传确认、数量刷新、更换相册关闭、复制／移动目标选择、路径摘要、新建目录弹窗取消和返回操作。目录列表较短时从顶部排列，主操作固定在导航区域上方。首次隐私拒绝、声明更新和图库拒绝通过执行生产代码的回归验证，未撤销真机已有隐私同意记录。

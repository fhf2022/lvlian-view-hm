# 音频播放页接入说明

参考版本：[`RzdPai/RzdMusic@5ec7e494`](https://github.com/RzdPai/RzdMusic/tree/5ec7e494220cc589e4395958251e26b8e18f8e5d/features/player)。

## 引入范围

`AudioPlayerPage.ets` 仅适配其播放页的封面、歌曲信息、进度、播放控制、底部操作布局。移除收藏、评论和迷你播放条；顶栏采用联文件的返回按钮。仅复制四个播放控制 SVG，附 Apache-2.0 许可及改动说明，位于 `resources/rawfile/licenses/`。

未引入上游播放服务、全局状态、账号、网络音源、搜索、评论、AMLL 歌词引擎、依赖包、构建或签名配置。页面组件只依赖系统 ArkUI/AVSessionKit 和联文件自身的布局、音频 UI 类型。

## 联文件自身实现

- 音频仍经过现有 NAS 下载、原图缓存、分享和下载通道，由现有 AVPlayer 管理器播放。新增的标签读取与 AVSession 适配器均为本项目代码；可选封面、标签读取失败不影响播放。
- 设置 → 默认视图新增「音频目录的默认视图」，支持列表、网格，复用既有分段选择器与首选项存储。仅使用已加载条目识别纯音频目录；混合文件或子目录仍使用普通文件默认。初始默认为普通文件夹列表、音频列表、图片网格，三组设置独立保存，已有用户选择保持不变；根页强制列表和本次运行的工具栏临时选择规则保持一致。
- 播放列表只包含打开时所在目录或当前搜索结果中已经加载的音频，不拉取完整 NAS 文件树。顺序循环、单曲循环、随机播放均使用该列表。
- 歌词只读取同目录同名 `.lrc`，上限 256 KiB、3,000 行；不调用在线歌词服务。歌词列表惰性挂载，高亮仅在当前行变化时更新。
- 返回时保留底层文件页。封面从实测位置飞回实测缩略图；落地前隐藏对应缩略图，结束后显示。切歌保留已测量的封面坐标。图片与音频共用返回目标准备及可视带滚动代码：列表、搜索和瀑布流只作必要的最小滚动，已完整可见则不动；普通网格沿用图片的原位返回策略，不为屏幕外目标滚动。源封面不可见或位置失效时淡出；惰性行挂载后在有限渲染帧内重新校正，不遗留返回后的延迟滚动回调，不干扰首划。
- 返回可视带使用文件滚动容器的实测原点和安全区换算，不再假设固定 94 vp 上沿；挂载后的校正等待布局提交，避免用旧矩形重复滚动。同一份容器测量同时供多选拖选使用。
- 打开时复用同一封面飞行层，从实测缩略图展开到播放页封面，背景和控制区同时淡入。下载及 AVPlayer 准备与动画并行，仅可选封面更新等待交接完成。打开途中返回沿用图片的待返回处理，完成封面交接后反向收起；立即销毁及过期回调不重开页面。
- 飞行层使用固定正方形图像的等比渲染缩放，容器负责位置、裁剪和圆角变化；`RenderFit.CENTER` 保证动态容器的内容居中，避免宽高动画把终态图片裁成局部。无专辑封面时按文件图标实际尺寸取起止位置。
- 关闭、切歌和账号切换使旧异步回调失效。文件描述符随 AVPlayer 释放；系统媒体会话及后台播放任务一并结束。没有常驻迷你播放条。
- 播放页所有图片和文本显式关闭系统数据拖拽，按钮图标不参与命中测试，由按钮处理点击。透明按钮关闭默认按压底色及悬停效果，输出设备入口继续使用官方组件；封面飞行层同样关闭图片拖拽。进度条拖动、歌词切页和封面动画沿用各自原有手势。

2026-10-21 返回定位共用化验证：真实 NAS 音频在播放、暂停时返回前后列表和网格位置一致；切到屏幕外曲目后，列表仅移到顶部可见边缘，网格保持原位并淡出。原生测量确认未重复提交滚动距离；正常 240 ms 包的返回及首划通过。Camera 图片的列表、网格、瀑布流返回前后位置一致。取消、惰性行挂载、安全区扩展、旧矩形和有界等待回归记录在 `temp/audio-player/media-return-regression.cjs`；真机结果在同目录的 `shared-return-*-results.json`。

系统输出设备选择使用原生 `AVCastPicker`。远端设备、NAS 音频格式和网络状态的完整组合仍需实际设备验证；本次本地合成音频检查不代表所有远端投播方式已验证。

## 音频封面与系统播控同步

- 文件列表和网格优先复用 NAS 缩略图；缺失时读取 MP3 的 ID3 图片帧、FLAC 的 PICTURE 块或 M4A 的 covr。读取使用现有鉴权 Range 通道，每次最多 16 个请求、累计 3 MiB，图片最多 2 MiB；跳过音频数据块，不为图标下载整首歌。单次读超时 3 秒，并有总耗时检查。
- 已缓存原文件使用系统 AVMetadataExtractor 补读封面，缩放后保存。封面沿用持久缩略图索引，以 NAS/账号、路径、修改时间和大小隔离；无封面结果短暂缓存，支持并发去重。列表的音频图标使用观察单条数据的组件，封面到达后局部刷新。
- 播放准备完成即建立系统媒体会话，标签和封面随后更新。元数据包含歌曲名、歌手、专辑和总时长；封面以有界 PixelMap 提交。没有封面时省略图片字段，避免原生接口拒绝整次元数据更新。
- 播放页和系统播控中心共用播放/暂停、上一首/下一首、进度跳转和循环模式入口。同步播放速度、采样时间和进度；seekDone 到达前忽略旧进度回调，避免拖动后短暂跳回。系统卡片配置返回本应用的启动入口，旧会话回调不能操作新歌曲。
- 合成 MP3、FLAC、M4A（不同封面、时长）及无封面 WAV 用于真机检查；系统播控中心封面、歌曲信息、时长、切歌、暂停、进度拖动和循环模式已验证。测试源码、素材及日志仅保留在 `temp/audio-player/`，正常包不包含测试入口。
- 真实 NAS 音频补充验证发现：播放页可显示的部分内嵌 JPEG，在原来的 ImageSource 解码参数下失败；回退到应用私有 URI 时系统播控无法显示。系统封面改用 `desiredSize` 限制解码尺寸并明确 RGBA 位图格式，失败时从最多 2 MiB 的封面压缩字节重试；不再向系统提交私有 URI。音乐封面单独居中裁为方形，最长边不超过 800px、小图适配官方 300px 最低尺寸，不改文件列表缓存尺寸。已在 `/home/fhf/Music/1` 验证 `summer bug`、`ココロスペアキー` 等真实歌曲的系统播控封面。
